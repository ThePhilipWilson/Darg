Persistence model

Completion by persistence: every run earns alignment, and each death at a capital wears that capital down. New game+ sets those dials to 0 to make completion a skill check.

Docs stay pure documentation. Tickets that came from this page link back to the heading, so "where did this card come from" is one click.

Regions

The Heartlands, the elven Court, the dwarven Citadel. Free Ports and the Athenaeum are planned with alternate slots.
